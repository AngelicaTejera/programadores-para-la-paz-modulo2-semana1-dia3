# Programadores para la Paz – Módulo 2 Semana 1 Día 3

## Actividad
JSON: organizar información comunitaria y leerla con Node.js.

## Objetivo
Comprender qué es JSON, para qué sirve y cómo puede usarse para organizar avisos y campañas comunitarias que luego serán leídas por Node.js y servidas desde Express.

## Enfoque ciudadano
Esta práctica se conecta con comunicación digital responsable. Una comunidad necesita organizar avisos, campañas, fuentes y propuestas de manera clara, verificable y fácil de consultar.

## Importante

Esta clase es introductoria.

No se trabajará base de datos.
No se trabajará autenticación.
No se trabajará login.
No se trabajará despliegue.
No se trabajará seguridad avanzada.
No se trabajará CRUD completo.
No se escribirá automáticamente en archivos JSON desde formularios.

## Comando nuevo del día

npm run datos

Este comando ejecuta un archivo de Node.js que lee archivos JSON.

## Comandos que se siguen practicando

npm install
npm start
git status
git add .
git commit
git push

## Rama de trabajo

No trabajes directamente sobre main.

Cada estudiante debe crear una rama propia con el formato:

nombres_apellidos

Ejemplo:

maria_gomez
carlos_rodriguez
ana_martinez_perez

## Evidencia

La evidencia se registra únicamente con el push de tu rama personal en GitHub.

No debes entregar archivos adicionales.
No debes subir capturas.
No debes publicar enlaces en Moodle.
No debes enviar evidencias por otro medio.
