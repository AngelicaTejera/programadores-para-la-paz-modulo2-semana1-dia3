Guía práctica – Módulo 2 Semana 1 Día 3

Actividad:
JSON: organizar información comunitaria y leerla con Node.js.

Repositorio:
Repositorio dispuesto por el docente.

Importante:
No debes trabajar directamente en main.

Cada estudiante debe crear una rama personal con el formato:

nombres_apellidos

Ejemplo:
maria_gomez
juan_perez
laura_torres_garcia

Evidencia:
La evidencia de esta actividad es únicamente el push de tu rama personal a GitHub.

No debes entregar nada en Moodle.
No debes enviar capturas.
No debes subir archivos adicionales.
No debes publicar enlaces por otro medio.

Comando nuevo del día:
npm run datos

Pasos obligatorios:

1. Clonar el repositorio

git clone URL_DEL_REPOSITORIO

2. Entrar a la carpeta del proyecto

cd NOMBRE_DEL_REPOSITORIO

3. Crear la rama personal

git checkout -b nombres_apellidos

4. Verificar la rama actual

git branch

La rama marcada con * debe ser tu rama personal, no main.

5. Instalar dependencias

npm install

6. Leer archivo JSON con Node.js

npm run datos

7. Revisar el archivo

data/avisos.json

8. Agregar un nuevo aviso comunitario al array

9. Ejecutar de nuevo

npm run datos

10. Levantar el servidor

npm start

11. Abrir en el navegador

http://localhost:3000

12. Probar botón Cargar avisos

13. Probar botón Cargar campañas

14. Abrir directamente la ruta

http://localhost:3000/api/avisos

15. Abrir directamente la ruta

http://localhost:3000/api/campanias

16. Modificar data/campanias.json agregando una nueva campaña

17. Detener el servidor con Ctrl + C

18. Levantar nuevamente el servidor

npm start

19. Probar nuevamente los botones del cliente

20. Completar los archivos:

semana4/conceptos-json.txt
semana4/bitacora-comando-dia3.txt
semana4/analisis-json-comunicacion.txt
semana4/reflexion-datos-comunitarios.txt

21. Revisar cambios

git status

22. Agregar cambios

git add .

23. Crear commit

git commit -m "JSON con Node modulo 2 semana 1 dia 3"

24. Publicar la rama

git push -u origin nombres_apellidos
